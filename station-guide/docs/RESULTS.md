# 검증 결과 (2026-11-27)

군자역(5·7호선) 3D 실내 길안내 프로토타입. 가진 자료(계획서, 군자역 영상 2개, 서울교통공사 공공데이터·API, 공개 구내도·시간표)만으로 검증했다.

## 1. 길 안내 (시나리오 A)
출발 26곳(출구 8, 승강장 4, 사진으로 찾는 위치 14) × 도착 12곳(승강장 4, 출구 8) × 계단 없는 경로 여부 (같은 곳끼리 제외) = **600개 조합 자동 점검** (`app/src/guide/scenarios.test.ts`)

| 점검 | 결과 |
|---|---|
| 경로가 있음 (엘리베이터 없는 출구의 계단 없는 경로 제외) | 전부 통과 |
| 개찰구를 맞게 지남 (들어갈 때·나갈 때 1번, 환승 0번) | 전부 통과 |
| 안내 단계가 경로 전체를 빈틈없이 덮음, 한 단계 걷기 120m 이하, 9단계 이하 | 전부 통과 |
| 계단 없는 경로에 계단·에스컬레이터 없음 | 전부 통과 |
| 한 단계 = 한 층 (층을 넘기 전 계단·엘리베이터 입구에서 단계를 끊음) | 전부 통과 |
| 같은 트인 구역 안에서 돌아가지 않음(직선의 1.5배+8m 이내), 개찰구 뒤 계단으로 곧장 | 전부 통과 (`app/src/guide/detour.test.ts`) |
| 계단·에스컬레이터·개찰구를 지난 뒤 방향(왼쪽/오른쪽), 단계 끝 주변 표식, 엘리베이터 버튼 | 생성 확인 (`app/src/guide/guidance.test.ts`) |
| 출구 → 승강장 + 승차권: 발매기가 개찰구보다 먼저 | 32개 전부 통과 |

전체 자동 테스트 72개 통과(데이터 무결성, 경사, 경로, 단계 문구, 매칭 규칙, 시간표, 서버 함수).

## 2. 표지판 사진으로 위치 찾기 (시나리오 B)
"쓸모 있음" = 바로 맞힘 + 후보 안에 정답 + 출구 표지판임을 알아내 번호만 물어봄. 어느 경우든 사용자는 버튼으로 확정한다.

| 결과 | 장수 |
|---|---|
| 바로 맞힘 | 32 |
| 후보 안에 정답 | 22 |
| 번호만 물어봄 | 3 |

표지판별로는 7호선 타는 곳·환승 표지판, 역 이름판(출구 번호)이 강하고, 화장실·방면 표지판이 약하다. 원본: `app/test-data/signs/synthetic-result.json`

### 2-3. 측정 중 고친 것
- OCR이 출구 번호 4를 8로 읽었는데 규칙이 확신한 사례 → 숫자 잡음이 있으면 확신하지 않고 번호를 묻게 수정(회귀 테스트 추가)
- 환승 표지판의 "7호선"이 깨져 읽히는 문제 → 타는 곳·갈아타는 곳 표지판의 단독 숫자 5·7을 호선으로 인식
- 작은 글씨 → 최대 확대 3배 → 4배 (영상 프레임 결과를 떨어뜨리지 않는 값으로 선택)

## 6. 알려진 한계
- 좌표는 안내도 기반 근사치(실측 아님). 승강장 위 계단·엘리베이터가 선로 쪽 1m 통로를 침범하지 않는지는 자동 점검(`app/src/station/layout.test.ts`)
- 구조는 두 안내도(5호선 in_2545, 7호선 in_2727)의 단면도·3D 그림으로 대조함(2026-11-27). 단면도는 승강장 165m 기준으로 환산(약 0.1m/px, ±5m 오차)
  - 지하1층: 가운데 십자 광장(개찰구 밖)에 출구 계단이 모임. 개찰구 안은 5호선 축(동서) 양쪽과 7호선 축(남북) 양쪽
  - 5호선 승강장 ↔ 지하1층: 승강장 양 끝 계단만(가운데 계단 없음). 양 끝에서 지하2층 환승통로로 내려가는 계단(환승정보 5→7 빠른 문 1-1·8-4와 일치)
  - 7호선: 지하1층 북쪽 에스컬레이터·남쪽 계단 → 지하2층 대합실(남북으로 한 판) → 북쪽 에스컬레이터·남쪽 계단·가운데 환승 계단 → 승강장(환승정보 7→5 빠른 문 5-1·5-2와 일치)
  - 내부 엘리베이터: 편의시설 API 위치 설명(내부1 장한평 5-3·아차산 4-1 = 가운데 동쪽, 내부2 장한평 4-3·아차산 5-1 = 가운데 서쪽)에 맞춤. 자동 테스트로 8m 이내 확인
  - 엘리베이터 앞 개찰구, 출구 엘리베이터 4번의 위치(단면 동쪽 끝 기둥), 7호선 고객안전실의 개찰구 안팎은 그림으로 확정 못 함(추정)
- 가동현황 코드는 'M'만 정상으로 가정
- 공휴일 달력 없음(일요일만 공휴일 시간표)
- 발권 순서·영문 역명은 공식 자료와 대조하지 않음
- 승강장 문 번호 위치는 8칸·칸 20m·문 4개·승강장 가운데 정차를 가정한 추정. 환승 빠른 문(5호선 1-1·8-4, 7호선 5-1·5-2)은 환승정보 공공데이터 기준
- 열차 모형은 목적지 승강장에 한 번 들어와 서 있다가 시간표 출발 시각에 한 번 떠난다(실제 위치 아님)
